Пользователи dashboard логин/пароль для входа

Здесь вы создаёте логин и пароль для каждого сотрудника, который должен заходить в этот dashboard. Роль «admin» даёт полный доступ (включая этот раздел), «employee» - обычный доступ, «salary» - видит ТОЛЬКО раздел «Зарплата» (для расчётного бухгалтера).

Колонки «Счетов» и «Сумма» показывают, сколько счетов этот логин лично изменил через dashboard (checkbox, ответственный и т.д.) - на основе журнала «АудитЛог».
